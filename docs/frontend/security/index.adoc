= Security

The Angular client holds no secrets and enforces no policy. Both jobs belong to the BFF (backend-for-frontend, the Spring Boot service in `consumer/`). Tokens live in cookies the page's JavaScript cannot read, authorization decisions happen server side, and every client-side check described here is a convenience, not a defense. This chapter describes how the client cooperates with that model. It covers the session and token lifecycle as the client experiences it, the identifier the client presents for its device, the step-up challenges it drives for sensitive actions, and the way it keeps personal data out of browser storage and audit events. Each section names the BFF security section that holds the server half of the story.
